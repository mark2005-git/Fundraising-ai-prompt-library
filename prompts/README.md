# Prompt Templates

This directory will contain versioned, structured prompt templates for the prototype.

## Initial workflow set

- `acquisition/` — illustrative campaign and audience messaging support.
- `stewardship/` — donor appreciation and engagement drafts.
- `retention/` — respectful re-engagement drafts.

## Template requirements

Every template should include:

1. A unique identifier and version.
2. Intended purpose and appropriate use.
3. Required and optional input variables.
4. Complete prompt instructions.
5. Explicit constraints and prohibited assumptions.
6. A defined output format.
7. A human-review checklist.
8. Synthetic test cases and evaluation notes.

Do not add real donor information or confidential organisational material. Templates in this repository are experimental examples and are not approved for operational use.
